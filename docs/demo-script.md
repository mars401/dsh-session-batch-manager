## 0 录制准备（两段通用）

**环境**

- 已安装本插件并重启过的 DSH Web GUI（开发沙箱 `http://127.0.0.1:13080` 或日常环境均可；桌面 App 未验证，不要用）。
- 安装验证：`curl -s http://127.0.0.1:<端口>/dsh-session-batch-manager/v1/status` 返回 `{"ok":true,"service":"dsh-session-batch-manager",…}`。
- 侧栏用宽布局，底部按钮带文字标签（「批量管理」「会话管理」在画面里可读）。

**语料建议**（决定画面信息量，录前 5 分钟准备）

- 会话总数 ≥ 10 个：首扫渐进加载更明显、表格更充实；
- 至少 1 个**运行中**会话（行首转圈圆点；可后台跑个任务）；
- 1–2 个**子代理**会话、2 个**已归档**会话（过滤 chips 有内容可切）；
- 若干**聊过几轮**的会话（缓存读/写非零，tooltip 有数可看）；
- 最好有 1 个上下文占用高的会话（≥ 90% 进度条变警告色；不强求）；
- **删除场景必须用可丢弃的测试会话**——删除是物理删除、不可恢复；
- 标题敏感的会话避免入镜，或事后打码。

**技术要求**

- 录屏工具：macOS `Cmd+Shift+5`（或 OBS）；16:9，建议 1920×1080（至少 ≥ 1280 宽，面板六列才完整显示）；
- 格式 mp4（H.264），每段一个文件；
- 鼠标移动放慢，关键 UI 停留 1–2 秒；
- 旁白**可选**：不录也行（提交时可配说明文字）；要录的话每场景下面给了一句备选台词；
- 正式录制前先空跑一遍流程熟悉操作。

## 视频 A · 侧栏批量操作（约 80 秒）

| # | 时间码 | 场景 |
|---|---|---|
| A1 | 0:00–0:08 | 开场：原生默认状态 |
| A2 | 0:08–0:15 | 点「批量管理」，选择框出现 |
| A3 | 0:15–0:28 | 多选 3 个会话，工具条出现 |
| A4 | 0:28–0:40 | 批量归档（含可选：停止并归档重试） |
| A5 | 0:40–0:55 | 切视图显示已归档 → 恢复 |
| A6 | 0:55–1:15 | 批量删除：确认 → 行消失 |
| A7 | 1:15–1:20 | 退出选择模式，收尾 |

### A1 开场（0:00–0:08）

- **操作**：展示侧栏默认状态，鼠标沿会话列表缓慢划过，最后指向侧栏底部的「批量管理」按钮。
- **画面必须拍到**：每行**行首没有选择框**；底部两个按钮——「批量管理」（清单图标）与「会话管理」（仪表盘图标）。
- **旁白备选**：「dsh 原生侧栏只能逐个归档会话，没有删除入口。」

### A2 进入选择模式（0:08–0:15）

- **操作**：点击「批量管理」开关。
- **画面必须拍到**：每行最左侧**出现选择框**；开关按钮高亮；此时无选中，底部工具条未出现。
- **旁白备选**：「点击批量管理，进入选择模式。」

### A3 多选（0:15–0:28）

- **操作**：依次点击 3 个会话行的**任意位置**（不必只点复选框，展示「点行即选中」；可以先点错一个、再点一次取消，体现切换语义）。
- **画面必须拍到**：被选行高亮；底部浮动工具条出现：**「已选择 3 个会话 · 全选 · 清空 · 归档 · 删除 · 退出」**。
- **旁白备选**：「点击行任意位置即可选中，底部出现批量工具条。」

### A4 批量归档（0:28–0:40）

- **操作**：点「归档」→ 等通知出现、行消失。
- **画面必须拍到**：结果通知**「已归档 3 个会话」**；对应行从列表消失；选择集自动清空（工具条收起）。
- **可选镜头**（选中的会话里有运行中的工作时才有）：通知带**「停止并归档 N 个运行中的会话」**一键重试按钮 → 点击它，展示重试成功。
- **旁白备选**：「归档立即生效；遇到运行中的会话，可以一键停止并归档。」

### A5 恢复（0:40–0:55）

- **操作**：打开侧栏会话列表顶部的**「视图选项」**菜单 → 选**「全部对话（显示已归档）」**（或「仅显示已归档」）→ 刚归档的行重新可见（带「已归档」徽标）→ 仍在选择模式，勾选这 3 行 → 工具条按钮自动从「归档」变为**「恢复」**→ 点击 → 通知**「已恢复 3 个会话」**，行回到活动列表。最后把视图选项切回「隐藏已归档」。
- **画面必须拍到**：视图选项菜单三项；已归档徽标；工具条按钮**「归档」→「恢复」**的变化；恢复通知。
- **旁白备选**：「切换视图显示已归档会话；选中后工具条自动变成恢复。」

### A6 批量删除（0:55–1:15）

- **操作**：勾选 2–3 个**可丢弃的测试会话** → 点「删除」→ 确认对话框 → 点「删除」。
- **画面必须拍到**：确认对话框标题**「删除 N 个会话？」**、正文（「将永久删除所选会话的日志文件，此操作不可恢复。…」）、目标会话列表；确认后「正在删除…」；**行立即消失**与通知**「已删除 N 个会话」**。
- ⚠️ **删除是物理删除，不可恢复——务必用测试会话。**
- **旁白备选**：「删除前有确认；确认后物理删除日志文件，行立即消失。」

### A7 收尾（1:15–1:20）

- **操作**：点「退出」退出选择模式；画面停留 1 秒。
- **画面必须拍到**：选择框隐藏、开关取消高亮。

## 视频 B · 会话管理面板（约 100 秒）

| # | 时间码 | 场景 |
|---|---|---|
| B1 | 0:00–0:08 | 入口 → 打开全屏面板 |
| B2 | 0:08–0:22 | 渐进加载（骨架 → 追加 → 已更新） |
| B3 | 0:22–0:38 | 六列表格逐列展示 |
| B4 | 0:38–0:50 | 过滤 chips 四视图 |
| B5 | 0:50–1:10 | Token / 缓存 / 上下文明细 tooltip |
| B6 | 1:10–1:30 | 面板内批量归档与删除 |
| B7 | 1:30–1:35 | 关闭面板 |

### B1 打开面板（0:00–0:08）

- **操作**：点击侧栏底部「会话管理」按钮（仪表盘图标）。
- **画面必须拍到**：入口按钮；全屏面板打开、标题**「会话管理」**、右上角关闭按钮 ✕。
- **旁白备选**：「侧栏底部的会话管理，打开全屏面板。」

### B2 渐进加载（0:08–0:22）

- **操作**：打开面板后**不动鼠标**，让首扫自然跑完（语料大时明显；小库一闪而过也正常）。
- **画面必须拍到**：骨架行 → 新行自底部**追加**（已有行不跳动）→ 顶部状态**「正在读取 N 个会话…」**与进度条推进 → 完成后切**「已更新 HH:MM:SS」**。
- **旁白备选**：「首次扫描全量日志，行渐进填充，界面不会卡住。」

### B3 六列表格（0:22–0:38）

- **操作**：鼠标从左到右**缓慢**划过表头与数据行，逐列停留。
- **画面必须拍到**：① 选择框列 ② 会话列（标题 + **运行中**圆点 / **子代理** / **已归档** / **置顶**徽标）③ 模型列（`provider/model`）④ Token 消耗列（紧凑数如 12.3k）⑤ 缓存读/写列（两个数）⑥ 上下文列（进度条 + 百分比；若有 ≥ 90% 的行，停 2 秒展示**警告色**）。
- **旁白备选**：「每个会话一行：模型、token 消耗、缓存读写、上下文占用一目了然。」

### B4 过滤 chips（0:38–0:50）

- **操作**：先勾选 1 行 → 依次点击「**子代理**」→「**已归档**」→「**主会话**」→「**全部**」，每次停留 1 秒。
- **画面必须拍到**：四个 chips 及其**计数**；行集随过滤变化；切换过滤时**选择被清空**（体现独立选择集）。
- **旁白备选**：「四个过滤视图，一键聚焦子代理或已归档会话。」

### B5 数值明细 tooltip（0:50–1:10）

- **操作**：回到「全部」，选一行**聊过几轮**的会话，依次把鼠标悬停（触屏可点按）在 Token 消耗、缓存读/写、上下文三个单元格上。
- **画面必须拍到**：Token tooltip 的四桶明细（**输入（未缓存）/ 输出 / 缓存读 / 缓存写** + 「该会话累计总量，含 fork 继承的前缀」脚注）；缓存 tooltip 的两个全量精确值；上下文 tooltip 的**「~used / window · N%」**与参考值说明。
- **旁白备选**：「悬停即可查看分桶明细与精确值。」

### B6 面板内批量操作（1:10–1:30）

- **操作**：勾选 2–3 行（点行即可）→ 面板工具条**「已选择 N 个会话 · 全选 · 清空 · 归档 · 删除 · 刷新」**→ 点「归档」→ 行**带「已归档」徽标留在表内**→ 点「刷新」（或停 5 秒等自动轮询，画面里「已更新」时间变化）→（可选）切到「已归档」chip，选中 1–2 个**可丢弃的**会话点「删除」→ 走确认对话框 → **行立即消失**。
- **画面必须拍到**：面板工具条；归档后行上的已归档徽标；删除后行立即消失。
- **旁白备选**：「面板内同样可以批量归档与删除；删除后行立即消失。」
- ⚠️ 删除镜头同样只用可丢弃的测试会话。

### B7 关闭（1:30–1:35）

- **操作**：按 `Esc` 或点右上角 ✕ 关闭面板。
- **画面必须拍到**：面板关闭、回到原界面。
